# 我的开发环境

工欲善其事,必先利其器。这里记录一下我日常写代码用到的一套工具。

## 编辑器

- 主力是 VS Code,装了几个顺手的小插件
- 偶尔用 Vim 快速改配置文件

## 终端

- zsh + 一些别名
- 常用 `git`、`pnpm`、`curl`

```bash
alias gs='git status'
alias gp='git push'
```

工具本身不重要,顺手的才重要。
