# 黑白简约静态博客 · 设计文档

日期:2026-09-20
状态:待评审

## 1. 目标

一个个人静态博客,黑白极简风格,以「纸质文件」为贯穿首页与阅读页的视觉隐喻,并带克制而丝滑的动作特效。核心诉求:展示的不只是文章列表,而是「一叠可以滑动浏览的纸质文件」。

## 2. 技术选型

- **框架**:Nuxt 4(最新稳定版,4.5.2,Vue 3),静态生成模式(`nuxi generate`),输出纯静态站点。
- **内容**:Nuxt Content 3(最新稳定版,3.16.0,面向 Nuxt 4 的新一代模块),Markdown + frontmatter 编写文章。
- **包管理器**:pnpm。
- **部署**:git 托管(如 GitHub)+ 静态托管平台(实现阶段确定,建议 Vercel / Netlify / GitHub Pages)。
- **版本原则**:全程使用最新稳定版本。
- **用户背景**:熟悉 Vue 3,未用过 Nuxt —— 实现时需说明 Nuxt 约定式路由、Nuxt Content v3、静态生成等 Nuxt 特有机制,无需重复 Vue 基础。

## 3. 设计语言

- 纯黑白配色:黑底(近纯黑,如 `#0a0a0a`)、白纸(`#ffffff`)、黑字,灰阶仅用于次级信息与阴影。
- 「纸」的隐喻贯穿:首页卡片是一页页纸,阅读页是一张放大的纸。
- 字体:实现阶段选定(倾向中文友好的衬线或等宽标题 + 无衬线正文),保持黑白克制的排版气质。

## 4. 信息架构

| 页面 | 路由 | 说明 |
| --- | --- | --- |
| 首页(封面流) | `/` | 核心页面,垂直/水平可切换的无限循环纸质卡片流 |
| 文章详情页 | `/posts/[slug]` | 黑底 + 居中白纸的阅读页 |
| 标签筛选页 | `/tags/[tag]` | 列出某标签下的所有文章 |

- **导航**:顶部极简导航,仅「站点标题/logo + 搜索入口」,**悬浮覆盖(fixed overlay)**在内容之上,不占据布局空间。**无关于页**。
- 搜索以模态层或下拉形式呈现,不做独立搜索页。

## 5. 首页:封面流(Coverflow)

### 5.1 布局

- 封面流容器**占满整个视口**(`100dvh`,从页面最顶部 `top:0` 开始);导航栏 `position: fixed` 悬浮于顶部,透明/渐变背景,不把内容往下推。
- 黑底,卡片**垂直居中聚焦排列**;中间一张**最大最亮**,上下卡片按距离**缩小并变暗**(竖版 coverflow)。卡片集中在视口中间,顶部与底部自然留白,因此不会被悬浮导航栏遮挡。
- 滚动时卡片滑入中心被「点亮」。

### 5.2 滚动交互

- **驱动**:鼠标滚轮 / 触摸滑动,用户自主控制(可停可快),带惯性缓动,追求丝滑手感。
- **无限循环**:滑到最后一张后无缝接回第一张(通过首尾克隆 + 位置重映射实现)。

### 5.3 布局切换(核心新增特性)

- 顶部提供一个切换按钮。
- 默认**垂直**分布(上下滑)。
- 点击切换 → 整个列表**逆时针旋转 90°**,变成**水平**分布(左右滑);再点 → **顺时针旋转 90°**,转回垂直。旋转本身是流畅的过渡动画。
- **水平模式下的滑动触发**:桌面端将滚轮的纵向增量映射为横向位移(向下滚 = 向右滑);触摸屏直接左右滑。水平模式同样支持无限循环。

## 6. 卡片设计(文档式纸张)

每张卡片是一页竖版 A4 比例的纸,内容自上而下:

1. 页眉:文件编号(文章序号)+ 细分割线
2. 标题
3. 摘要(几行)
4. 底部分割线 + 日期与标签

**交互**:
- hover:卡片轻微抬起、阴影加深(呼应聚焦放大手感)。
- 点击居中卡片 → 放大过渡进入文章详情页。

## 7. 文章详情页

- 黑底上浮一张**居中窄栏白纸**,阅读即「在看这张纸」。
- 顶部:标题、元信息(日期、标签、阅读时长)。
- 正文:Markdown 渲染,代码块、标题、列表等样式统一为黑白文档风。
- 底部:上一篇 / 下一篇 / 返回首页。
- 独立 URL `/posts/[slug]`,SEO 友好、可分享。

## 8. 标签与搜索

- **标签**:文章 frontmatter 声明;卡片与文章页展示;点击标签 → `/tags/[tag]` 筛选页。
- **搜索**:顶部搜索入口 → 模态搜索框;客户端全文搜索(标题 + 摘要 + 正文);即时下拉结果,点击跳转文章页。

## 9. 动效清单

1. **首页无限循环滑动**(核心)—— 丝滑惯性 + 无缝循环。
2. **布局切换旋转动画** —— 垂直 ↔ 水平,90° 旋转过渡。
3. **卡片 → 文章页过渡** —— 点击卡片放大无缝进入阅读页。
4. **卡片 hover 微交互** —— 抬起 + 阴影加深。
5. **滚动 reveal** —— 文章页元素随滚动淡入上浮。
6. **背景颗粒噪点** —— 黑底加极淡胶片颗粒,增加质感(静态质感层)。
7. **开场加载动画** —— 进入首页时卡片/标题淡入展开的入场。

明确不做:鼠标跟随类特效。

## 10. 内容模型

Markdown 文件 `content/posts/*.md`,frontmatter:

```yaml
---
title: 文章标题
date: 2026-09-20
tags: [设计, 随笔]
summary: 摘要文字
hidden: false   # 可选,true 则隐藏该文章
---
正文……
```

- `slug` 由文件名派生。
- **文件编号(index)自动生成**:不在 frontmatter 中手写。封面流按 `date` 升序自动为文章分配编号(01,02,03…),写入卡片页眉;用户无需维护编号。如需自定义顺序,可加可选 `order` 字段(数字,越小越靠前)覆盖默认的日期排序。
- **隐藏文章**:`hidden: true` 的文章不出现在首页封面流、标签页、搜索结果中,且静态生成时**不生成其独立文章页**(彻底隐藏,草稿不泄露)。
- 文章规模:初期十几篇,后续持续增加,内容层需支持无痛扩容。

## 11. 目录结构(规划)

```
blog/
  content/posts/*.md          # 文章
  pages/
    index.vue                 # 首页(封面流)
    posts/[slug].vue          # 文章详情页
    tags/[tag].vue            # 标签筛选页
  components/
    Coverflow.vue             # 封面流容器(滚动/循环/旋转)
    PaperCard.vue             # 纸张卡片
    SearchModal.vue           # 搜索
    ...
  composables/
    useCoverflow.ts           # 滚动、循环、惯性逻辑
    ...
  assets/css/                 # 全局黑白主题、颗粒噪点等
```
